PSOrvia Klangvergleich

PSOrvia · psorvia.io

Hear and see what changed between two sounds. Both versions play at the same time and you switch between them without a click; the spectrum morphs with the switch, the real spectrum of the running sound moves over it, and the partials and the decay are marked. Plain JavaScript and CSS, no dependencies.

Usage

<link rel="stylesheet" href="klangvergleich.css">
<script src="klangvergleich.js"></script>
<script src="klangvergleich.i18n.js"></script> <!-- only for languages other than English -->
<div id="kv"><audio controls src="before.m4a"></audio> <audio controls src="after.m4a"></audio></div>
<script>
PsoKlangvergleich.create(document.getElementById('kv'), {
  lang: 'en',
  before: { src: 'before.m4a' }, after: { src: 'after.m4a' },
  data: { /* JSON from tools/vorrechner.py --ansichten */ },
  views: ['spectrum', 'wipe', 'diff', 'level', 'stereo', 'glow'] // optional, the first is the start view; default is only 'spectrum'
});
</script>

Besides the spectrum there are five more views, each switchable with the views option: a wipe divider over the two spectrograms, a difference map (added and removed energy), the level over time with the playback position, the stereo image as point clouds with correlation, and a glow of the live spectrum with a soft afterglow. All are drawn in canvas at full device resolution; tools/vorrechner.py --ansichten computes their data in advance.

The audio elements inside the container are the fallback without JavaScript or Web Audio; the script replaces them.
